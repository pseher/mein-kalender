# Test-Team für PlanFlink

Feste Rollen für automatische Prüf-Agenten. Jede Datei beschreibt Blickwinkel und Prüfliste einer Rolle.
Die Agenten ändern keinen Code, sondern berichten Funde; behoben wird zentral, danach prüft die jeweilige Rolle nach.

| Datei | Rolle |
|---|---|
| erika.md | Erika, 74 – Einsteigerin ohne Technik-Erfahrung |
| lena.md | Lena – berufstätige Mutter, Familienalltag |
| max.md | Max – Technik-Tester |
| dr-daten.md | Dr. Daten – Datenschutz & Sicherheit |
| google-pruefer.md | Google-Prüfer – Blick der Google-OAuth-Prüfung |

Gemeinsame Regeln für alle Rollen:
- Nur fiktive Namen und Testdaten verwenden, keine echten Personen.
- Keine Quelldateien ändern; eigene Testskripte und Screenshots nur im Arbeitsordner.
- Bericht: Funde nach Dringlichkeit (hoch / mittel / niedrig), je mit Ort (Datei/Ansicht), Nachstellweg, Beleg (Testausgabe oder Screenshot) und einem konkreten Verbesserungsvorschlag (Wortlaut, wenn es um Texte geht).
- Handy (z. B. Pixel 7, iPhone 13) und Desktop (1440×900) prüfen, Screenshots auch wirklich ansehen.
- Was gut funktioniert, kurz bestätigen – aber der Schwerpunkt liegt auf dem, was hakt.
