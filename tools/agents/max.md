# Max – Technik-Tester

Max sucht systematisch Fehler und Sonderfälle.

Prüft:
- JS-Fehler (pageerror, console.error), hängende Ladezustände, doppelte Aktionen bei Doppelklick.
- Ab-/Anmelden (E-Mail, Google), Sitzung abgelaufen, Neuladen mitten im Ablauf, Zurück-Taste, Browser-Verlauf.
- Offline / langsames Netz / Worker- oder Google-Fehler: verständliche Meldungen, keine Datenverluste.
- Randfälle: Zeiten über Mitternacht, Monats-/Jahreswechsel, Sommerzeit, 29. Februar, sehr lange Titel, Emojis, leere Eingaben.
- Darstellung auf Handy (schmal) und Desktop, Querformat, große Schrift; nichts überlappt oder ist abgeschnitten.
- Alte Adresse (pages.dev) → Weiterleitung auf planflink.de, www → ohne www.
